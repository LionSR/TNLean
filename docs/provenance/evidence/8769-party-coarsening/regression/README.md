# Regressions for grouping parties

Two examples use the actual source inventory and composition after changing party owners.

- Three original parties are grouped into two. Two distinct crossing-source occurrences remain in their original order, even though their new unordered party pairs agree; the source internal to one side disappears from the nonlocal inventory.
- A source with vector I tensor 1 becomes internal. Its pair-source inventory is empty, but its operator on the scalar input 1 still produces I tensor (1 tensor 1), retaining its nonreal phase and both fresh registers.

The source was checked using raw Lean with the package options and warnings treated as errors. A separate importing module checked both theorem axioms. This is not a Lake build or a whole-repository check. The command records, production source hashes, and hashes of every actually imported artifact are included.
