# Regressions for selective source preparation

Three scalar sources have endpoint pairs (1,2), (0,1), and (2,1), in that order. Only the middle source is free. The partition singles out party 0, so both fixed sources are internal, while the free source crosses the partition.

The checked examples establish the exact free register layout, the ordered fixed-source inventory including reversed endpoints, the empty inventory for an all-free mask, and the complete original inventory and empty free input for an all-fixed mask. They also prove the mixed operator recovery for arbitrary free vectors and obtain two contractions chosen before that arbitrary family. Spectator registers are arbitrary throughout.

The regression source was compiled by raw Lean with the package options and warnings treated as errors. A separate importing module checks every regression theorem's axioms. This is not a Lake build or a whole-repository check. Command records, exact production source hashes, and hashes of every imported artifact are included. Source-revision fields are populated only after the checked bytes and artifacts are verified against the source commit.
