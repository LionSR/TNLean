# Free-source block regressions

Two examples use the actual free-source matrix and trace theorems.

- An imaginary matrix unit with two ket input coordinates and three bra input coordinates pairs with the bra-row, ket-column block. The ket and bra sources and endpoint index types are independent.
- An identity word with no source slots has precisely the physical identity matrix, without an extra source coordinate or scalar.

The source was checked using raw Lean with the package options and warnings treated as errors. A separate importing module checked both theorem axioms. This is not a Lake build or a whole-repository check. The command records, production source hashes, and hashes of every actually imported artifact are included.
