# Scalars from gates with no participants

Five modules identify the product of original empty-participant coefficient sums, bound its modulus by one, identify its exact occurrence in the chronological residual, and show that a scalar can be absorbed into any existing network vertex without changing the bonds. The residual identities impose no participant nonemptiness or cancellation premise, and include vanishing coefficient sums. Absorption specifies an existing vertex.
