# Formalizing the spin-one Haldane gap

This is the working plan for a Lean formalization of a uniform spectral gap for
the periodic spin-one antiferromagnetic Heisenberg chain. It records the
sources, what is already on the branch, the route chosen, the finite numerical
inputs that stay outside Lean, how they were checked, and the staged work that
remains. It is meant to be read without the conversation that produced it.

Status (2026-10-08): stage 0 is done; stages 1–6 are planned.

## 3. Route chosen: the L ≥ 60 initialization only

Theorem 1.1 has two initializations. We formalize only the first,
`prop:seed60`, which gives

> For every even L ≥ 60 the periodic spin-one Heisenberg ring has a unique
> ground state and γ_L > (4/105) log(80/79) ≈ 4.79·10⁻⁴.

This already gives a uniform positive gap, so the Haldane gap in the
even-periodic form, Δ₁ = lim inf γ_L > 0. The second initialization
(`prop:seed2304`) only improves the constant to log(20)/784 ≈ 3.8·10⁻³ and
costs 18 more thermal certificates on rings of up to 12 sites, the 72-site
trial contraction, two degree-12 filters and a six-step rounded table. It can
be added later on top of the same infrastructure.

### Proof outline of the chosen route

1. **Model.** H_n(g) = Σ_j S_j·S_{j+1} on (ℂ³)^{⊗n}, with the last bond twisted
   by g ∈ {I, P, C}, P = diag(1, −1, −1) and C the cyclic permutation of the
   axes. Shift a = 700741/500000 and Z_n(b, g) = Tr exp[−b(H_n(g) + an)].
2. **Spatial moments** (`prop:transfer`, `lem:sectors`). For each b > 0,
   Z_n(b, g) = Tr(X_b^n U_g) for a self-adjoint X_b commuting with a signed
   permutation representation U of the rotation group generated by D₂ and C.
   The eigenvalues split into lists I, O (twice), N (three times) with
   Z_n = I_n + 2O_n + 3N_n, Z_n(P) = I_n + 2O_n − N_n, Z_n(C) = I_n − O_n.
3. **Purity criterion** (`prop:bootstrap`) with (n₀, b₀, u₀, C) =
   (60, 105/4, 1/8, 79/10), r = 79/80: from S(60, b₀) ≥ 7/8 and
   T(120, b₀) ≥ 7/8 conclude γ_L > log(80/79)/b₀ for every even L ≥ 60.
4. **Initialization** (`prop:seed60`), at b₀' = 21/2 then b = (5/2) b₀':
   the 9 thermal numbers bound the sector moments I₁₀, O₁₀, N₁₀; the filters
   F_I(x) = x⁶(−2 + 10x²)², F_N(x) = x⁶(−25 + 100x²)² bound the eigenvalue moduli
   by U = 1.00245 (I) and V = 0.88643 (N); capped masses give Z₃₀ bounds;
   Σ z^{5/2} ≤ (Σ z)^{5/2} moves them to b = 105/4; the trial bound Z₁₂₀ > 1 and
   the vertex maximization R(t) force one dominant weight w₀ > 0.998, which
   gives both purities above 7/8.

## 4. Design decisions

1. **No infinite-dimensional operator theory.** The preprint builds X_b as an
   integral operator on bond histories in L²(μ). Instead, Trotterize: apply even
   and odd bonds alternately in N time slices and expand each bond factor as
   1 + (b/N) Σ_α G_α⊗G_α, with G_α = iS^α real. For even L this gives an exact
   finite identity Z_L^{(N)}(b) = Tr (Y Yᵀ)^{L/2} with Y an explicit real
   matrix indexed by bond-label words. A twist g acts on bond labels by a signed
   permutation, because g G_α g⁻¹ = ±G_{σ(α)}, so the twisted traces are
   Tr((YYᵀ)^{L/2} U_g) with U_g finite. The whole argument of step 4 runs on
   this finite matrix for each N. Its conclusions S(60, b₀) ≥ 7/8 and
   T(120, b₀) ≥ 7/8 are closed inequalities, so they pass to N → ∞ once
   Z^{(N)} → Z. Only convergence is needed, never an explicit Trotter error.
   The thermal inputs carry strict margins (at least 4.7·10⁻⁵), so they still
   hold for the Trotter approximants when N is large.
2. **Inequalities as the interface.** Refactor `gapGT_of_purities` so that its
   spatial hypothesis is the three moment inequalities it actually uses
   (S ≤ 1, the squaring inequality, ℓᵖ monotonicity) rather than an exact
   eigenvalue list. Those inequalities are closed under limits.
3. **One general criterion.** Generalize stage 0 to Proposition 4.3 with
   parameters (u₀, C); the current u₀ = 1/100, C = 5 version becomes a corollary
   instead of a parallel copy.
4. **Finite facts as a hypothesis structure.** The numerical certificates are
   fields of one Lean `structure` about matrices that Lean itself defines. No
   `axiom`, no `native_decide`. The headline theorem takes the structure as an
   argument. Any field later proved in Lean is removed from the structure.

### Headline statement (target shape)

```lean
/-- Finite inputs of `prop:seed60` and `lem:trial-inputs`, about the Lean
definitions of the twisted Heisenberg rings. -/
structure SeedSixtyCertificate : Prop where
  thermal : ∀ n ∈ ({6, 8, 10} : Finset ℕ), ∀ g : Twist,
    |shiftedPartitionFunction n (21 / 2) g - center n g| < 1 / 10 ^ 5
  trial : groundEnergy 120 < -120 * (700741 / 500000)

theorem heisenberg_uniform_gap (h : SeedSixtyCertificate) {L : ℕ}
    (hL : 60 ≤ L) (hLe : Even L) :
    GapGT (heisenbergSpectrum L) (4 / 105 * Real.log (80 / 79))
```

## 7. Risks and open questions

* **Trotter factorization bookkeeping** (stage 4) is the main effort: the
  site trace must be written as a product over time slices with the left and
  right bond labels interleaved in a fixed order, and the transpose for the
  other parity of site must be checked. Prototype numerically on a 4-site ring
  before writing Lean.
* **Twist identification.** The preprint defines P and C as rotations on the
  seam bond (its eq. (2.3)) and gives the weight-basis matrices by eq. (2.5).
  The Lean definition must match the matrices the verifier actually used;
  stage 6 checks this by building the matrices from the Lean-side definition.
* **Lie–Trotter in Lean** is not in Mathlib at the pinned version. A
  QICLean search comes first; otherwise prove ((1 + A/N)(1 + B/N))^N → exp(A + B)
  for matrices directly.
* **Trial inequality in the kernel.** Python needs 26 s with arbitrary-size
  integers; the Lean kernel is likely too slow for 162×162 powers up to 118
  with numbers of hundreds of digits. If it is, the field stays in the
  certificate structure.
* **Faithfulness.** The headline theorem is the preprint's L ≥ 60 statement
  with the ten finite inputs as hypotheses. Under the repository's
  faithfulness rule it must not carry `\leanok` against `thm:main` until those
  hypotheses are discharged in Lean; until then a paper-gap note records them.
