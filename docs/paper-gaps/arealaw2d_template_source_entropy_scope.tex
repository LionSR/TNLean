The actual separated-template covering theorems now supply the two entropy
antecedents used by the source scanner.  For one fixed exponent $e>0$ and
one coefficient controlling every safe rectangle, a single $C_e\geq0$
is chosen before all domains, unit vectors, cuts, templates and scales.
It controls the target by $C_e n^{1+e}$ and every actual positive-depth
prefix by $C_e(nL^e+n)$.  The proof derives $s_0\leq n$ from the actual
template, identifies prefixes with ambient shells, and uses the established
safe dyadic partitions.  Arbitrary partial final rows obey the same bound.

The physical specialization consumes the literal supremum bound
\[
  F_{\rm box}(r)\leq C_{\rm box}r^{1+2\cdot10^{-6}}
  \qquad(r\geq1)
\]
at fixed physical parameters and safety parameter.  The same original
gapped ground vector occurs in each safe rectangle, target and shell.
The resulting coefficient precedes the domain, Hamiltonian, ground vector,
cut, scanner and template.  No target or prefix entropy bound is assumed.
\footnote{Declaration:
    \leanid{TNLean.PEPS.AreaLaw.Scan.exists_template_final_source_entropy_bounds_of_boxEntropy}

The displayed safe-box supremum bound is the unresolved physical input
of Proposition 9.5, tracked in issue~8756.  The initial safe-box theorem
already supplies some uniform $0<e_0<1$; it does not supply $e_*=2\cdot10^{-6}$.
The finite iteration theorem assumes the physical one-step improvement
$e\mapsto(1-\ell)e$.  This module neither assumes an estimate at every
exponent nor treats that missing one-step improvement as proved.
In particular, the final sharp source theorem, which itself assumes
entropy at $e_*$, cannot establish this input without circular reasoning.

This result applies to separated templates.  The bootstrap application to
safe rectangles uses their weaker $D_0s_0$ clearance and its separate
weak-rectangle shell covering; the stronger template clearance must not
be imposed on that application.  The scalar bootstrap absorption and
finite iteration do not supply the physical rough-comparison pair.

No scanner construction, clearance theorem, low-energy selection,
Proposition 9.5, Proposition 9.6 or full area law is asserted here.
Hosted kernel, strict axiom and documentation checks remain required;
this scope note is not evidence of successful elaboration.
