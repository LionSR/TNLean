\section{Source statement}

\cite[Proposition~1]{Cirac2017MPU} asserts: if $E$ is the
transfer matrix of a matrix-product unitary with physical dimension $d$ and
bond dimension $D$, then $\tr(E^N)=1$ for all $N>1$, and consequently the
spectrum of $E$ contains a single eigenvalue equal to one with the rest
vanishing.  The paper cites Lemma~A.5 of \cite{Cirac2016MPDO_arXiv} for
this conclusion.

\section{The present formalization}

This PR (\ghpr{5732}) formalizes the algebraic step that a complex $n\times n$
matrix whose positive powers all have trace~$1$ must satisfy
$\chi_A(X) = X^{\,n-1}(X-1)$.  The proof is purely algebraic via Newton--Girard
identities: equality of all positive-power traces to~$1$ forces the reverse
characteristic polynomial to be $1-X$, hence the characteristic polynomial
$X^n-X^{n-1}$.

The hypothesis requires $\tr(A^k)=1$ for \emph{all} $k\ge 1$, including $k=1$.
The source only supplies moments for $N>1$ from unitarity of blocked tensors.
In the source context the first moment $\tr(E)=1$ follows from the definition
of $E$ as a normalized partial trace of a unitary; the purely algebraic
consequence of the stronger all-positive-moment hypothesis is the correct
prerequisite for the downstream MPU transfer argument.

\section{The $k>1$ conclusion}

The source's exact $k>1$ conclusion is handled by \ghissue{5737}, which
derives $\tr(E)=1$ from $\tr(E^N)=1$ ($N>1$) for the specific transfer matrix
$E$ using the fact that $E$ is a positive map whose spectral radius is~$1$.
The spectral mapping $k\mapsto k^2$ (or $k\mapsto k^3$) together with the
Perron--Frobenius structure of the transfer matrix yields the missing first
moment, after which the present theorem applies.  The algebraic multiplicity
statement (exactly one eigenvalue~$1$, the rest~$0$) follows from the
characteristic-polynomial factorization proved here, but the multiplicity
witness (separation of the $1$-eigenspace) is a distinct theorem not included
in this PR.
