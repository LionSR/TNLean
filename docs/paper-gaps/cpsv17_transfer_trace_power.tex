\section*{Paper gap: Transfer trace-power lemma—positive dimension restriction}

\textbf{Source:} arXiv:1703.09188, Proposition \texttt{prop:normal-tensor}, lines 349–354.
The source states that for the transfer matrix $E$ of a matrix-product unitary,
$\operatorname{tr}(E^N) = 1$ for all $N > 1$ forces the spectrum of $E$ to
contain a single eigenvalue equal to one with the rest zero.

\textbf{Formalization:} The theorem is formalized as
\verb|Matrix.charpoly_eq_X_pow_pred_mul_X_sub_one_of_forall_trace_pow_eq_one|
(and its finite-range counterpart) in \verb|TNLean/Algebra/TracePowerCharPoly.lean|.

\textbf{Scope restriction:} The Lean statement requires
$0 < \operatorname{Fintype.card}\; n$ as an explicit hypothesis. In the
source context $E$ is the transfer matrix of a unitary tensor, whose index
type always has at least one element (the bond dimension $D \ge 1$, hence
$\dim E = D^2 \ge 1$). For a $0 \times 0$ matrix the trace of every power is
$0$, so the hypothesis $\operatorname{tr}(E^k) = 1$ would be contradictory.
The restriction is therefore semantically harmless but syntactically present.

\textbf{Elimination plan:} If a context arises where the index type could
be empty, derive the positive-cardinality condition from the hypothesis
$\operatorname{tr}(A^1) = 1$ via \verb|Fintype.card_pos_iff|. This derivation
is a one-line lemma and can be added when needed; the current statement with
the explicit hypothesis is used in downstream MPU transfer-spectrum arguments
that already carry a positive-dimension context.

\textbf{Status:} Local fix (scope restriction). The theorem as stated is
mathematically faithful to the source when the index type has at least one
element, which it always does in the source application.
