% Five examples, designed to be completed in about fifteen minutes.
\section{A fifteen-minute tutorial}\label{ch:tutorial}

The five examples use the same reading order: layout, picture policy, then
body declarations.  Each source is complete and uses canonical public syntax.

\subsection{An MPS word}

\begin{tnexample}[
  formula={(A^{i_1}A^{i_2}A^{i_3})_{\alpha\beta}},
  caption={a regular contraction},
  index={The horizontal bonds are summed virtual indices.  The two stubs are
    the open matrix indices; each upward leg is one physical index.},
  signature={boundary|virtual-west=1|virtual-east=1|physical-up=3|physical-down=0}]
% Formula: (A^{i_1} A^{i_2} A^{i_3})_{alpha beta}
% Ink: bonds contract; stubs and up legs are open indices.
\begin{tenkz}[physical=up,west label=$\alpha$,east label=$\beta$]
  \tn[up=$i_1$]{A} & \tn[up=$i_2$]{A} & \tn[up=$i_3$]{A}
\end{tenkz}
\end{tnexample}

The environment chooses a contraction grid.  \tnkey{physical=up} is picture
policy.  Each \tncmd{tn} declares an atom; \verb|&| advances one site.

Beamer reads a frame's body before typesetting it, under the catcodes in
force when the frame opens, so a chained picture's \verb|&| is still an
alignment tab and the frame stops with a misplaced-tab error.  Mark the frame
\texttt{[fragile]}; beamer then defers that reading until the picture's own
catcode for \verb|&| applies.

\subsection{A channel sandwich}

\begin{tnexample}[
  formula={\mathcal E_A(X)=\sum_i A^i X A^{i\dagger}},
  caption={the channel applied to $X$},
  index={$X$ closes the east input pair.  The west pair remains open because
    the output is a matrix; the vertical connection sums $i$.},
  signature={boundary|virtual-west=2|virtual-east=0|physical-up=0|physical-down=0}]
% Formula: E_A(X) = sum_i A^i X A^{i dagger}.
% Boundary: the input closes east; the matrix output stays
% open west.
\begin{tenkz}[sandwich,east={cup=$X$}]
  \tn{A} \\
  \tn*{A}
\end{tenkz}
\end{tnexample}

\tnkey{sandwich} declares ket over bra and pairs their physical legs.  The
star declares the conjugate atom.  A cup connects adjacent layers; it is not
a same-row trace.

\subsection{Compose an equation}

\begin{tnexample}[
  formula={B^i=XA^iX^{-1}},
  caption={pictures compose as mathematical atoms},
  index={The capsules are matrices on the wire and add no indices.  Both
    sides expose one west stub, one east stub, and one physical leg.},
  signature={boundary|virtual-west=1|virtual-east=1|physical-up=1|physical-down=0}]
% Formula: B^i = X A^i X^{-1}; both boundary signatures agree.
\[
 \begin{tenkz}[physical=up] \tn[up=$i$]{B} \end{tenkz}
 =
 \begin{tenkz}[physical=up]
   \tnX{X} & \tn[up=$i$]{A} & \tnX{X^{-1}}
 \end{tenkz}
\]
\end{tnexample}

Ordinary TeX owns the equals sign.  Each picture remains an independent
model and event stream; the audit compares their boundary signatures.

\subsection{Select a lattice region}

\begin{tnexample}[
  formula={S=R\smallsetminus\{(2,2)\}},
  caption={regions are cell-set data},
  index={The tracer measures the outer contour and the hole.  Boundary legs
    are the virtual indices cut by the finite window.},
  signature={lattice|rows=4|cols=4|region=2}]
% Formula: S = R minus {(2,2)}.
% Ink: the region contour is derived from its cell set.
\begin{tenkzlattice}[rows=4,cols=4,boundary=open]
  \tnregion[slot=selected,name=R,label=$R$]{(1-3,1-3)}
  \tnregion[slot=secondary,outline,label=$S$]{R - (2,2)}
  \tnsite[removed]{(2,2)}
\end{tenkzlattice}
\end{tnexample}

The layout owns site positions.  \tncmd{tnregion} declares measured cell
sets, and \tncmd{tnsite} changes one site record.  No polygon is hand traced.

\subsection{Join an irregular typed graph}

\begin{tnexample}[
  formula={\sum_\alpha A_\alpha^{\mathsf T}TB_\alpha},
  caption={typed ports make the free layout auditable},
  index={The straight join contracts the virtual index $\alpha$.  The arc
    connects physical ports and carries $T$.},
  signature={free|atoms=2|joins=2}]
% Formula: sum_alpha A_alpha^T T B_alpha.
% Boundary: both joins connect equal port types.
\begin{tenkzfree}
 \tnput[ports={east:virtual,north:physical}]{a}{(0,0)}{A}
 \tnput[ports={west:virtual,north:physical}]{b}{(14mm,0)}{B}
 \tnjoin{a.east}{b.west}
 \tnjoin[route=arc,out=90,in=90,label=T]{a.north}{b.north}
\end{tenkzfree}
\end{tnexample}

Coordinates place atoms; they do not type the graph.  \tncmd{tnput} declares
names and typed ports, while \tncmd{tnjoin} declares connections between
those ports.  Joining unequal types is a hard error.
