\section{Troubleshooting and maintenance}\label{ch:trouble}

\subsection{Read meaning before ink}

Open the job's \tnfile{.tnlog} and find the picture's coded diagnostic and
boundary event.  A matrix needs two open virtual indices, a doubled-space map
needs four, and a scalar needs none.  Compare an equation side by side, not
merely by total count.

{\small
\noindent
\begin{tabularx}{\linewidth}{@{}
  >{\raggedright\arraybackslash}p{35mm}
  >{\raggedright\arraybackslash}X@{}}
\toprule
Symptom & First correction \\
\midrule
A map rendered as a scalar & State \tnkey{boundary=open}, or type the open
ports; an unstated side draws no leg. \\
A trace looks like a layer cup & Use \tnkey{boundary=periodic} for same-row closure;
use side \tnval{cup} only between adjacent layers. \\
A label touches ink & Restore a documented metric or label band; do not hide
the problem with an undocumented coordinate offset. \\
Requested ink disappears & Treat it as an implementation defect.  Unsupported
ink must be a hard coded error, never a warning followed by omission. \\
\bottomrule
\end{tabularx}
}

Brace any key value containing a comma or a second equals sign.  A conjugate
is label mathematics and a wire direction, not an atom flag.  A genuine hole
is \tnkey{void=open}, because its incident indices survive; \tnkey{void=sealed}
removes the site and its bonds.

\subsection{Maintainer pipeline}

The internal flow is

\begin{center}
\texttt{language -> model -> style/atoms -> geometry -> kernel layout ->
rendering -> events}.
\end{center}

Language owns declarations and diagnostics.  Model owns normalized records.
Style owns metrics, atom descriptors, label policy, ports, and silhouettes.
Geometry owns frames, measurement, daylight, routing, and crossings.  Dialect
layout owns only genre-specific placement.  Rendering emits ink without
parsing syntax or changing topology.  Events serialize the resolved model
used by rendering.

\tnfile{tenkz.sty} is a logic-free load map.  Each internal file begins with a
five-line contract naming its input, output, owned state, invariants, and next
stage.  Private control sequences follow one owner-prefixed convention; the
symbol census rejects accidental exports.

Build and debugging commands live in \tnfile{HACKING.md}; the full ownership
contract lives in \tnfile{ARCHITECTURE.md}.  After every meaningful change,
compile, lint, audit the versioned event stream, render, and inspect the
affected pages.  Exit codes do not inspect diagrams.
