% Typed atom extension and document house style.
\section{Atom extension and house style}\label{ch:house}

The stock atom skins are shared across layouts.  A dot is an unnamed tensor
site, a box or pill carries an inscribed label, an MPO has physical input and
output faces, and a ring is a matrix on an existing wire.  The semantic kind,
typed ports, and visual skin are separate data.

\subsection{Declare one typed atom}

Use \tncmd{tndeclare} only when the stock atom vocabulary cannot express a
recurring mathematical kind:

\cmdsig{\textbackslash tndeclare\{atom\}\{\meta{command}\}\\
\{skin=\meta{dot|box|pill|mpo},\\
\hspace*{2em}ports=\{\meta{face:type},\ldots\}\}}

\begin{Verbatim}[fontsize=\small,frame=leftline]
\tenkzkernel
\tndeclare{atom}{\tnprojector}{
  skin=box,
  ports={180:virtual, 0:virtual, 90:physical}
}
\begin{tenkz}[cols=1] \tnprojector{P} \end{tenkz}
\end{Verbatim}

A face is an angle in the atom's own axes: \tnval{180} and \tnval{0} are the
two ends of the wire, \tnval{90} is above and \tnval{270} below.  Types are
\tnval{virtual} and \tnval{physical}.  The declaration creates a
one-label atom command with optional per-use cell keys.  Its port list is
complete: an anchor without a type is not an extension contract.

\whynote{The declaration adds a new atom kind and therefore a new word in the
atom class.  A skin or role change on an existing atom is a key instead.}

There is no \tncmd{tndefine}.  Naming a repeated whole figure would hide the
grammar benchmark and create a second topology source.  Compose ordinary TeX
macros only outside canonical benchmark bodies, and keep their expansion in
public tenkz syntax.

\subsection{Extension gate}

A new key needs at least three manifested RMP consumers.  A new command needs
a new grammatical class.  Every accepted capability also needs a registry
entry, a standalone example of roughly fifteen lines or fewer, a stable coded
diagnostic, a negative test, and a teachability review.

\subsection{House style}

Use \tncmd{tnset} for document-wide metric or semantic policy and picture keys
for local policy.  Themes may rebind semantic hues and typography; they do not
add topology.  Use roles for meaning and labels for identity.  Never assign
arbitrary colors to distinguish tensors of the same kind.

Labels occupy reserved bands outside measured silhouettes.  If an entire
picture needs more room, use the documented metric or layer separation.  A
manual coordinate nudge is the last resort and is never canonical benchmark
syntax.  The geometry stage measures occupied ink and separates it with one
daylight constant.
