\section{Compatibility spellings}\label{ch:compatibility}

Compatibility aliases read older documents.  New manual, benchmark, test, and
blueprint sources use canonical spellings.  This registry-generated table is
the exhaustive alias list; it is empty since the surface swap, when the last
four aliases died with the front end that parsed them.  \tncmd{tenkzkernel}
remains callable and rebinds the surface the package already bound at load,
so a document that still spells it changes nothing.

Aliases normalize to the same semantic events as their replacements and may
not change type, default, scope, or diagnostics.  The canonical-only linter is
authoritative for benchmark cases: replace an alias instead of adding a
manifest exception.  Historical records in \tnfile{docs/tenkz/history/} do not
define supported aliases.

There is no compatibility form of \tncmd{tndefine}: it was an aspirational
promise, not a shipped public grammar.  Typed custom atoms use
\tncmd{tndeclareatom}.
