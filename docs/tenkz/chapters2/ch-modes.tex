\medskip

A spatial lattice, sheet, window, or
measured region is not a second layout: it is a \tnenv{tenkz} picture with
a frame -- \tnkey{lattice=} or \tnkey{planes} sugar, or a declared basis.

\paragraph{Do not change layouts for style.}
The layout shares the metric, atom skins, semantic roles, labels, and
connection policy across every picture.  A chain does not become a
coordinate drawing because it is vertical.  Choose the layout once, then
declare policy through its public keys.

\paragraph{When none fits.}
State the missing mathematical class before adding syntax.  A new key needs
three manifested RMP consumers.  A new command needs a new grammatical class.
Until that gate passes, the honest result is a capability request, not raw
TikZ hidden inside a canonical source.
