\section{Which environment?}\label{ch:chooser}

Choose from topology, not from the desired appearance.

\medskip

\tnenv{tenkzplanes} is the ket-over-bra preset of
\tnenv{tenkzlattice}; it is not a separate genre.  Use it when every site of
two matching sheets is the datum.  \tncmd{tnpic} is the inline composition
wrapper for one \tnenv{tenkz} body; it is not a fifth layout.

\paragraph{Do not change layouts for style.}
The genres share the metric, atom skins, semantic roles, labels, and
connection policy.  A chain does not become a coordinate drawing because it
is vertical.  Choose the layout once, then declare policy through its public
keys.

\paragraph{When none fits.}
State the missing mathematical class before adding syntax.  A new key needs
three manifested RMP consumers.  A new command needs a new grammatical class.
Until that gate passes, the honest result is a capability request, not raw
TikZ hidden inside a canonical source.
