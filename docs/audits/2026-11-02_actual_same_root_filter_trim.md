# Actual filtering and collective trimming at the same root

The literal native operator is conjugated to full-interval coefficient
coordinates. The next space is the collective trim of the standard
orthonormal basis of the actual image of the current space. Its native
image is constructed from the current root rather than supplied independently.
The existing full-interval product-coordinate identity is made public with
its proof unchanged.

One common native reference controls every candidate space and step. Its
whole-exterior internal-cut rank remains the square of its all-span MPS
bond. The actual QICLean filter-and-reference-trim theorem gives

    delta_next <= (1-c/4) delta + c eta/8

under epsilon_reference <= c^2 eta/1024 and
xi sqrt((L-1) D_reference^2) <= c eta/48. The filtered image inclusion,
coordinate invariance, orthogonal-complement invariance and norm estimates
are transported from the literal native operator. No closeness of the
entire filtered image to the entire trimmed space is assumed.

The actual candidate dimension does not increase. Every next candidate
has a recorded spanning family of size at most the preceding dimension,
and each recorded vector satisfies xi^2 rank <= the same dimension.
This is not the bond bound for every vector in the span; the extra
spanning-family factor remains necessary there.

The one-step theorem is an auxiliary with explicit normalized-filter
hypotheses. Constructing the physical normalized filter, choosing the
physical reference and threshold, defining the actual finite iteration,
and applying compressed Ritz extraction are separate obligations. The
printed multiplicative overlap gain is replaced by the corrected
normalized recurrence, as documented in
`docs/paper-gaps/alvv16_final_filter_gain.tex`. The collective trimming
constant is documented in QICLean's published trimming-constant note.
The full source algorithm and its running time are not asserted here.
