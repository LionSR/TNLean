# The same concrete joint success event

The new definition names exactly the event already used in the actual
repeated-sampling tree's conditional joint failure bound: root viability
with error `3/200`, and, for every parent on the actual balanced merge list,
retained viability with that same error and the same literal original-target
stopped history. Its complement unfolds to the existing failure event.
Neither a second tree nor a parallel family of success predicates is added.

The event is measurable for every valid root. The proof combines the existing
actual root and node viability events with the existing actual history events.
The long interval index is a subtype of natural endpoint pairs, so its
membership-guarded conjunction is a countable intersection. No finite-index,
eigenbasis-selection, initial-viability or probability-success premise occurs.
The existing conditional probability theorem is not copied or changed.

Temporary inspection commands were removed.

Combined ordinary gates remain required. No provider, dependency pin, cache or
Mathlib source was modified. The final physical construction must still
discharge the existing fixed-candidate probability and parent implication
before claiming its numerical joint success probability.
