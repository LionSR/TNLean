# Joint probability for the actual physical sampled tree

The same physical collection of clipped targets, finite improving families
and common reference is selected once, before the common radius, children
and global product Haar seed. The resulting literal interleaved balanced
recursion is viable for the original full ground space at the root and
all internal intervals actually descended from that root, outside a set
of probability at most (L-1)/(L+1)^2. The true joint event is Borel and its
probability is at least the complementary bound. The dimension and
recorded-generator rank bounds hold for every seed, including failures.

The proof does not assume its desired event is measurable, impose a
conditional probability oracle or select new families after observing
children. It uses the existing unconditional size theorem to discharge
child dimensions in the existing fixed-child analytic bound, then applies
the proved guarded-event joint probability theorem to that same operation.
The latter derives the true sections, independence from the fresh parent
coordinate and the finite union estimate. Only actual root descendants
are asserted simultaneously viable. The original target includes the
whole interval exterior, with no restriction to product target vectors.

theorem passed imported foundation inspection in 7.950 seconds with 789
