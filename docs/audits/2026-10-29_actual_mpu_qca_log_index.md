The supplied-standard-form support theorem computes the actual blocked QCA's
positive rational index ell/d^k. The existing canonical MPU theorem computes
its index at the same simple block as minus log-base-two(ell/d^k).
This change combines them for the actual named induced automorphism.

Equality of all physical periodic matrices at lengths greater than one now
implies equality of actual induced quasi-local automorphisms, including across
different virtual dimensions. One buffered chain contains the input and both
source-radius neighbourhoods; actual finite evaluation compares the physical
matrices and completion density extends the equality. The named automorphism
also equals the supplied completed automorphism as an actual equivalence.

A bare positive-dimensional MPU has a reduced canonical representative of bond
E≤D with equal positive-length periodic matrices. Its derived simple block has
0<k≤E²≤D². The canonical source gates give an actual nearest-neighbour blocked
QCA and the logarithmic equality. Actual-action family independence transports
that QCA; the existing representative-index theorem transports the MPU index.
No canonical datum, simple block, nearest-neighbour support bound, support-factor
presentation or index equality is a public input to the final theorem.

The existing paper-gap note records the Appendix's extra factor two and reversed
dagger placement; this change uses the definition's negative single logarithm.
The theorem compares the actual derived nearest-neighbour blocked presentation.
It does not assert a separate arbitrary regrouping-invariance theorem.
