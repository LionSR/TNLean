The Kronecker collision is NOT a drop-in replacement: TN's theorem accepts
rectangular matrices and empty index types; the candidate QIC theorem requires
square matrices and `Nonempty` indices. Deleting TN's theorem and replacing its

`Lattice/Sheet/SwapCorrection` and `PEPS/Approximation/TwoSheetExchange`.
A coherent pin-switch must preserve that generality (for example, resolve the
upstream generality discrepancy first), not add nonemptiness to consumers.

The four Volterra declarations can move to QIC's existing Analysis/Volterra:
the source diff contains only copyright/documentation and local option removal.
The ordered-product duplicate must disappear with DisjointRelativeEvolution.
The two global commutator declarations must be removed from the TN LR owner in
the same pin-switch. Removing only the ordered-product declaration is insufficient.

## Minimum coherent implementation slice

1. Resolve all eight pin collisions together, retaining the rectangular/empty
   Kronecker theorem's generality. Apply the fixed QIC revision consistently in
   TOML and manifest only once dependency/compilation checks are available.
2. Consume ManyBody projected/disjoint/Gaussian results directly and delete all
   four requested TN modules. Delete Volterra's duplicate owner and the global
   commutator duplicates; retarget their imports and existing references.
3. Reconcile the *existing* support/expectation/evolution owners and migrate the
   relevant localization producers and consumers together. This is not a text
   import replacement: TN support is a Set-indexed span Submodule; QIC support
   is a Finset-indexed StarSubalgebra over arbitrary basis families. TN's
   siteExpectation uses uniform-dimension normalization and embedOp; QIC uses
   regionExpectation, configuration cardinality and place. In particular the
   GridPropagation hcompare input and hUsupport output do not have the old
   expectation/support types after a mere callee rename.
4. Consume ManyBody.GraphBall and ManyBody.crossingTerms directly for support
   separation; do not introduce a second crossingTerms or forwarding API.
5. Regenerate only necessary aggregators, retarget Blueprint owners, then verify
   all changed sources and the affected closure with strict flags and required
   aggregates. Preserve statements, constants, zero/empty cases and quantifier
   order (the chosen path precedes observable/filter parameters).

The wider dependency surface is material: reverse import closures contain 326
modules for SiteExpectation, 1,178 for SupportedOperators, 312 for
