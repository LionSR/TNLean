# Unconditional bounds for the actual sampled interval tree

One physical collection of clipped targets, finite operator families and
reference spaces is chosen before the children, radius and global random
seed. Every space retained by the existing balanced recursion has dimension
at most D^6 s^3 and the corresponding recorded-generator rank bound, on
every history. The true fixed-child failure bound is retained for the same
collection. Viability is not assumed to prove these unconditional bounds.
The joint tree probability statement is a separate consequence.

The full-space short-leaf proof is shared by the previous sampled tree and
the new canonical tree. Its natural-number count is shared by the two
earlier physical tree constructions and the new physical data theorem.
All five pre-existing public signatures are byte-identical; only their
proofs and imports changed. The window length ell is distinct from the
independent energy cutoff t.

The four new public declarations and five existing consumers passed strict
actual-module checking and a combined imported foundation inspection. The
inspection took 7.785 seconds and protected 785 selected source/object
pairs. All dependencies use at most propext, Classical.choice and
Quot.sound; the arithmetic lemma does not use Classical.choice. The
inspection source was deleted. Final times were 4.565 seconds for the
arithmetic lemma, 4.839 for the full-space lemma, 4.915 for the generic tree,
8.299 for the old sampled tree, 13.310 and 15.614 for the two earlier
physical trees, and 15.134 for the physical sampling data. An earlier
required check of the first physical tree took 26.197 seconds, exceeding
the 25-second warning threshold but remaining below 50 seconds. This
observation is retained; no timing-only rerun or budget increase was used.
The later importer refresh followed correction of the shared helper's
window-length documentation.

Checks used held TN 435cbe7fe5 and its own QIC b2ea12a0 with exact selected
source/object, input, importer-closure and prebuilt Mathlib guards. The
source-only TN branch contains the already-owned interval sampling
operation as a prerequisite commit; that prerequisite is not part of the
new contribution. No .lake was created, no artifact was copied and no
provider or cache was modified. Generated imports, source declaration
synchronization, reader-facing prose, proof integrity and whitespace were
checked. Ordinary builds and compiled blueprint checks belong to the
coordinated integration.

The result retains block leaves, the fixed failure target (L+1)^(-2),
the capped gap min(gamma,1), the actual hard-clipped family and the local
current-space assignment correction. It does not assert runtime or the
unrestricted printed quantitative profile. See
`docs/paper-gaps/alvv16_approximation_parameters.tex`.
