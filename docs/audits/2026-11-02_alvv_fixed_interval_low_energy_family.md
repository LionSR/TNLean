# A low-energy improving family on every prescribed interval

The physical low-energy construction now treats every interval of the
actual chain, including empty intervals, short intervals and intervals
meeting a chain endpoint. One constant depending on the declared fixed
bandwidth precedes the chain, local dimension, numerical count base,
width and interactions. The same scalar ceiling, degree and count envelope
are used throughout. There is no global spectral-gap assumption and no
supplied residual, spectral ceiling, tensor decomposition, improving
family or sampling budget.

The regional theorem constructs the actual three-bulk clipping and its
common polynomial family on any region whose symmetric difference from
the native interval has at most two window lengths. Its unconditional
numerical fields precede the geometric hypotheses. Extracting those
fields therefore does not assume an impossible window fit in the short
case. The native public theorem is a specialization of this shared proof
and retains its full public signature.

For a long prescribed interval, the existing inward-cut theorem supplies
the actual interior cuts and a collar with at most two window lengths.
The exact decomposition of the same global polynomial on the prescribed
region has the actual collar cardinality cost. That cost fits the same
$D=(m\ell^2)^{22\ell}$ chosen for the suppression estimate: the
cardinality is at most $D^2$ and $D^{12}\Delta\le10^{-5}$. The
physical dimension and Hamiltonian are unchanged when the numerical
count base exceeds the local dimension. No count enlargement is made
after choosing the filter.

For a short interval, existing actual configuration matrix units improve
every viable subspace for every target, including the zero target. Take
both auxiliary targets to be the original canonical upper target; equality
and inclusion give the two spectral comparisons. This direct branch does
not assert a separate global polynomial filter. Both branches produce
exactly $D^2$ operators, chosen before the buffered cutoff and before
every viable subspace. Zero extension preserves each actual image span.

All original targets use the raw Hamiltonian's canonical minimum and
eigenbasis. The physical interval and its configuration isometry are fixed
independently of the selected clipping scale. Thus this construction
discharges the geometric dependency needed for a least-dimension argument
on one fixed regional Hilbert space. The least-dimension induction,
finite first-success proof, LD rank bound, entropy and MPS conclusions
remain separate. The statement retains the explicit fixed-bandwidth and
$q\ge2$ scope, documented in
`docs/paper-gaps/alvv16_low_energy_family_scope.tex`.

The projection argument for self-closeness had two existing gapped
consumers. The companion order module now proves inclusion/self-closeness
and contains the existing error-monotonicity theorem with its signature
and proof unchanged. Both gapped consumers and the new short branch use
that shared result. The existing gapped public signatures are unchanged.

Every selected source, object, package input and prebuilt Mathlib sentinel is
guarded. Every selected importer of a changed source is re-elaborated with an
explicit override. Outputs remain private; no provider or cache is changed.
