\chapter{Polynomial filters with the AKLV Schmidt-rank bound}
\label{ch:aklv_polynomial_filters}

This chapter proves the polynomial Schmidt-rank estimate of
\cite[Lemma~4.2]{Arad2013AreaLaw}, with explicit universal constants
(Theorem~\ref{thm:aklv_polynomial_rank}). It then constructs a Chebyshev
polynomial whose evaluation at the same supported Hamiltonian has both
this rank bound and exponential suppression away from the ground state
(Theorem~\ref{thm:aklv_physical_chebyshev_filter}).
