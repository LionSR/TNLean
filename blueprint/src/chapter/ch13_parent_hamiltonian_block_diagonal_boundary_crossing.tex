\subsection{Cyclic windows at the boundary cut}\label{subsec:block_diagonal_boundary_crossing}

A cyclic length-$L$ window either stays inside the chosen linear interval
($i+L\le N$) or crosses the boundary cut ($N<i+L$). Whereas trace cyclicity
settles the non-wrapping case, the crossing case requires a boundary-matrix
identity $\mu_j^NX_jA^j_\beta=A^j_\beta Y$; together, the two cases establish
the single-block periodic membership
$\Gamma_N^{A_j}(\mu_j^NX_j)\in\mathcal G_{N,L}(A_j)$.
