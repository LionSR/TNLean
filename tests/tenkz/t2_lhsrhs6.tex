% Formula:  the 2D analog of step 1: a PEPS window whose interior
% carries the tensors A, B (LHS) resp. B, C (RHS), one uncovered site
% keeping only its physical index, and a boundary operator L resp. R
% living on the annular band around the window, contracting all cut
% virtual indices:
%   sum A^{s_a} B^{s_b} L({beta}, s_x) |s>  =
%   sum B^{s_b} C^{s_c} R({beta}, s_y) |s>.
%
% Declarative reading: oblique lattice sheet; the covered patch is the
% inset=1 outline (the region the Hamiltonian term acts on), the outer
% outline is the boundary band labelled L resp. R; physical=up puts the
% on-site physical legs; the uncovered site sits between the two rims.
%
% Noted gaps (this figure exercises two missing lattice primitives):
%   * per-site labels: tenkzlattice sites are anonymous beads — the
%     A/B (resp. B/C) tile labels, the load-bearing difference between
%     the two sides, cannot be written on the sheet;
%   * a removed site deletes its whole column including the physical
%     leg, so the reference's dangling physical index inside the band
%     (the uncovered site) cannot be spelled: here the uncovered site
%     is drawn as an ordinary bead outside the inner rim.
% Verdict intent: still-blocked on `\tnsite` label support (exact key:

\[
  % LHS: interior patch (cols 1-2 of a 2x3 window) inside the L band
  \begin{tenkzlattice}[rows=2, cols=3, frame=oblique, physical=up]
    \tnregion[outline, inset=1]{(1-2,1-2)}
    \tnregion[outline, label=$L$, label at=south east]{(1-2,1-3)}
  \end{tenkzlattice}
  \;=\;
  % RHS: interior patch (cols 2-3) inside the R band
  \begin{tenkzlattice}[rows=2, cols=3, frame=oblique, physical=up]

  \end{tenkzlattice}
\]
