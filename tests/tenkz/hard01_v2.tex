Left orthonormality: the two-layer core is declarative; the west closure
(contraction over $\alpha$) and the identity right-hand side are stated
algebraically because the inter-layer bend has no key yet.
\[
  % sandwich = rows={ket,bra}: physical leg of A_L pairs onto conj(A_L);
  % boundary=open (default) draws the four virtual stubs.
  % Content drawn: sum_s |...>: [A_L^s] (x) conj([A_L^s]) with s contracted.
  \sum_{\alpha}\;
  \begin{tenkz}[sandwich,
                west label={$\alpha$}, east label={$\beta$}]
    \tn[box]{A_L}\\
    \tn*[box]{A_L}
  \end{tenkz}
  \;=\; \delta_{\beta,\beta'}
  % (west stubs of ket and bra carry the same summed index alpha; the RMP
  %  draws this identification as a cup and the delta as a bare cup.)
\]

Right orthonormality, same core with the roles of the sides exchanged:
\[
  \sum_{\beta}\;
  \begin{tenkz}[sandwich,
                west label={$\alpha$}, east label={$\beta$}]
    \tn[box]{A_R}\\
    \tn*[box]{A_R}
  \end{tenkz}
  \;=\; \delta_{\alpha,\alpha'}
\]
