% Formula (unitarity of the blocked two-site tensor):
%   sum over the internal virtual pair (gamma gamma') of
%     U^{i_1 s_1}_{alpha gamma} U^{i_2 s_2}_{gamma beta}
%     conj( U^{i'_1 s_1}_{alpha' gamma'} U^{i'_2 s_2}_{gamma' beta'} )
%   =  [ U conj(U) b ]_{alpha alpha'}^{i_1 i'_1}
%      (x)  [ a U conj(U) ]_{beta beta'}^{i_2 i'_2}
% — the two-column ket-over-conjugate window factorizes: the shared
% internal virtual pair is replaced by the gauge matrix b closing the
% east side of the LEFT column and the gauge matrix a closing the west
% side of the RIGHT column (Cirac-Perez-Garcia-Schuch-Verstraete,
% caption of fig. sec2fig7b(a)).
%
% Declarative reading:
%   LHS — rows={op,op}, two columns: op-onto-op pairing contracts the
%   facing physical legs per column, row bonds carry the virtual
%   indices, all outer legs open (vw 2, ve 2, pu 2, pd 2).
%   RHS — the same single-column sandwich twice: east={cup=$b$} on
%   the first factor, west={cup=$a$} on the second (cup dots are the
%   house style for the reference's circled letters).

  \end{tenkz}
  \;=\;

  \;
  % RHS, factor 2: right column, west side closed through a

    \tn*{U}
  \end{tenkz}
\]
