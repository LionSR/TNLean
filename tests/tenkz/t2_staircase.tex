% generation of an MPS by a staircase of isometries.
%
% Formula:  |psi> = V_5 V_4 V_3 V_2 |0>,   V_k : H_beta -> H_{i_k} (x) H_beta
% an isometry per site: it consumes the virtual output of the previous
% step and emits one physical index i_k plus the next virtual index; the
% first input is the fixed virtual state |0>, and the LAST isometry's
% both outputs stay open (the reference's top V has two open legs, so
% five open physical/virtual indices in total).
%
% Orientation: the grid's circuit convention is quantikz-like — wires are
% ROWS and time flows west -> east; the reference is the same picture
% rotated 90 degrees (time up, staircase ascending right).
%
% Declarative reading:
%   \tn[dot]{|0>}        — the source bead on the trunk wire.
%   \tn[box, wires=2]{V} — each isometry is a one-atom brick terminating
%     both spanned wires at its edges (quantikz \gate[2]); wire k is BORN
%     at V_{k-1} and runs open to its east stub after V_k, so the east
%     stubs protrude at staggered columns exactly like the reference's
%     staggered short legs.
%   west=none            — per-side boundary policy: rows born mid-picture
%     have no west index (the hard11 gap).
%

% and nothing ever reads it, so all five west stubs are drawn and the
% boundary signature logs virtual-west=5 where the reference has 0.
% Everything else (staggered east outputs, wires=2 bricks, |0> bead)
