% Regression: a traced row's closure is one contour with the row it closes,
% and a name that speaks to the side the return runs on stands clear of it.
%
% The rail used to begin at its own reach point, one wrap reach out from the
% row's first cell, so on the row's centreline no ink ran between the rail
% and the chain: the picture recorded a periodic contraction and drew an open
% one.  Two short probes astride the row line, one in each gap, count the
% leads that close it.  A label band shallower than the trace reach put every
% site name across that same return; the step a label owes the return is
% counted through the one function that computes it.
%
% The joined return then ran through the row it closed.  It stood a fixed
% trace reach from the row line, and the first row here hangs a named
% physical index on that very side: a leg, and the band its name occupies.
% The leg alone is longer than the reach, so at stroke width every open index
% of the row ended on the wire that contracts it, and its name stood on the
% far side of that wire from the index it names.  Two probes on the first
% site's own axis pin the daylight the return now keeps: one reaching to
% just inside it meets no return, and one reaching just past it meets exactly
% one.  Both are written in the metric names, so the clearance is the one the
% table declares and not a number this file remembers.
