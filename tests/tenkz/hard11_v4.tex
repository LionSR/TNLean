% Formula:  |psi> = ( prod_{layers l} (x)_k U^{(l)}_k ) |0>,

%
% Declarative reading:
%   \tn[box, wires=2]{} — an unlabeled brick TERMINATING both spanned
%   wires at its edges (quantikz \gate[2]); layer offsets rows 2-3,
%   then 1-2 / 3-4, are the brick pattern.
%   \tn[dot]{|0>} — the source bead on the trunk wire; its label takes
%   the free south quadrant (the reference's beside-the-dot label).
%   west=none — the word's WEST side carries no open indices: every
%   wire is either prepared (the |0> bead) or born at a gate edge, so
%   no west stub is drawn anywhere.  boundary=open (the default) keeps
%   the four EAST stubs: the state's open physical indices.
%   Expected boundary signature: virtual-west=0, virtual-east=4.
